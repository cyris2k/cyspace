# Pink Pixel Village

Public production build of a cozy pixel-art portfolio.

Visit: https://cyris2k.github.io/pink-pixel-village-site/

Walk with WASD or arrow keys, press E or Enter near a place, or click/tap a destination. The grid button opens direct navigation.

This repository contains only the self-contained browser build. The editable source project is kept in a separate private repository.

GitHub Pages serves the root of the main branch.
